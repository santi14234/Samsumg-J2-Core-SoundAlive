# Samsung SoundAlive Universal (Web & Android APK)

Recreación completa de Samsung SoundAlive para Android Go (Samsung Galaxy J2 Core) y cualquier navegador moderno.

## 🚀 Compilación del APK en GitHub Actions:

1. Repositorio vinculado: `https://github.com/santi14234/Samsumg-J2-Core-SoundAlive`
2. Ve a la pestaña **Actions** en tu repositorio de GitHub: `https://github.com/santi14234/Samsumg-J2-Core-SoundAlive/actions`
3. Selecciona el flujo **«Compilar APK SoundAlive con GitHub Actions»** y pulsa **Run workflow** (o deja que corra con cada commit de sincronización).
4. GitHub compilará el proyecto automáticamente usando Java 17, Android SDK y Gradle.
5. Al terminar con éxito (✅), en la sección **Artifacts** descarga el archivo **`SoundAlive-Galaxy-J2-Core-APK`**.
6. Descomprime y pasa el archivo `app-debug.apk` a tu Samsung Galaxy J2 Core para instalarlo.
