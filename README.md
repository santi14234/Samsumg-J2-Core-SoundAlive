# Samsung SoundAlive Universal (Web & Android APK)

Recreación completa de Samsung SoundAlive para Android Go (Galaxy J2 Core) y cualquier navegador moderno.

## 🚀 Compilación del APK en GitHub Actions:

1. Sube estos archivos a tu repositorio de GitHub: `https://github.com/santi14234/Eq-Soundalive`
2. Ve a la pestaña **Actions** en GitHub.
3. Selecciona **Compilar APK SoundAlive con GitHub Actions** y pulsa **Run workflow**.
4. GitHub compilará el proyecto con Java 17, Android SDK y Gradle.
5. Al terminar, en la sección **Artifacts** descarga el archivo **`SoundAlive-Galaxy-J2-Core-APK`**.
6. Pasa el `.apk` a tu teléfono e instálalo.
